# My-Private-Space

موقع شخصي (Portfolio) — `index.html` + `app.js` + مجلد `assets/` للصور.

## الملفات
- `index.html` — هيكل الموقع + التصميم (CSS).
- `app.js` — منطق الموقع: البيانات، العرض، ونظام الأدمن.
- `assets/` — الصور (`portrait.png` + `photo1..5.webp` + `hero-cutout.png` صورة الهيرو بدون خلفية + `shot-portfolio.webp` و `shot-rawdat.webp` لقطات كروت المشاريع).

## الأقسام
Hero · نبذة عني · المهارات · معرض الصور · الخدمات · الرحلة العلمية · المشاريع · تواصل معي (نموذج + حسابات).

## لوحة التحكم (Admin)
لوحة التحكم وكل أزرار التعديل **مخفية عن الزوار** بالكامل. للدخول:

- اضغط على شعار الموقع (MM) **3 مرات**، أو
- اضغط `Shift + A`، أو
- افتح الرابط مع `#admin` (مثال: `.../index.html#admin`).

كلمة المرور الافتراضية: `Mazen@2026`

> لتغيير كلمة المرور: غيّر `ADMIN_PASSWORD_HASH` في `index.html` بهاش SHA-256 للكلمة الجديدة.
> مثال: `python3 -c "import hashlib;print(hashlib.sha256('كلمتك'.encode()).hexdigest())"`

الجلسة محفوظة في `sessionStorage` (بتنتهي بإغلاق التاب). زر الخروج موجود في شريط "وضع المدير".

### إمكانيات اللوحة (تابات)
- **عام:** الاسم عربي/إنجليزي، نبذة الهيرو، نبذة "من أنا؟"، السطر الصغير، كلمة الهيرو، نصوص الأزرار، رابط السيرة الذاتية، صورة الهيرو (بالاختيار من الصور المتاحة).
- **النصوص والعناوين:** تعديل عناوين وأوصاف كل الأقسام (Kicker + الكلمة الأولى + الكلمة الذهبية + الوصف)، وعناوين/نصوص كروت النبذة ونموذج التواصل.
- **المهارات:** تعديل اسم/نسبة كل مهارة (سلايدر 0–100%)، وإضافة/حذف المهارات ونقاط الاهتمام.
- **الخدمات والرحلة:** إضافة/تعديل/حذف الخدمات ومحطات الرحلة.
- **الصور:** إضافة/حذف صور المعرض وتعديل روابطها وتسمياتها، واختيار صورة الهيرو.
- **التواصل:** روابط إنستجرام/تيك توك/واتساب/لينكدإن/جيت هاب + البريد.

زر **"استعادة الافتراضي"** يرجّع كل البيانات للقيم الأصلية.

## ربط البيانات بـ Vercel
طبقة البيانات معزولة في `DataStore` جوه `app.js`:

- **القراءة:** `window.SITE_DATA` ← ثم `GET /api/data` ← ثم `localStorage` ← ثم القيم الافتراضية.
- **الكتابة:** `POST /api/data` (بالـ JSON) ← وإلا `localStorage` كـ fallback.

عقد الـ API:

```
GET  /api/data                       -> 200 + JSON  (نفس شكل DEFAULTS في app.js)
POST /api/data  {pass, data}         -> 200 {ok:1}  (يتطلب ADMIN_PASSWORD)
POST /api/data  {..الكائن كامل..}    -> 200 {ok:1}  (العقد القديم بدون pass، يعمل لو ADMIN_PASSWORD غير مضبوط)
```

`api/data.js` جاهز ومستضاف على Vercel. كل اللي محتاجه متغيّرات البيئة:

| المتغيّر | الوصف |
| --- | --- |
| `KV_REST_API_URL` أو `UPSTASH_REDIS_REST_URL` | رابط قاعدة Upstash Redis |
| `KV_REST_API_TOKEN` أو `UPSTASH_REDIS_REST_TOKEN` | توكن Upstash Redis |
| `ADMIN_PASSWORD` | كلمة سر الحفظ على السيرفر (المستحسن ضبطها لحماية الكتابة) |

**مهم:** بدون قاعدة Redis وكلمة السر دي، تعديلات لوحة التحكم تُحفظ في `localStorage` بمتصفحك فقط ولا تظهر لأي زائر آخر.
